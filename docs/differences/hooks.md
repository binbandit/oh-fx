# Hooks and Herdr reporting

- Foreground Herdr reporting uses `OH_FX_HERDR` for the application opt-out while retaining the third-party `HERDR_SOCKET_PATH` and `HERDR_PANE_ID` variables and the upstream `custom:fx` source and `fx` names. Working starts when the terminal accepts `TurnStarted`; upstream reports working when an interactive prompt is admitted, before the provider starts. Startup reports the actual opened session, then idle and both names; visible permission and question activation report blocked, matched turn completion reports idle, and terminal shutdown releases authority before a handled termination signal is re-raised. The release is serialized with reports and permanently closes the reporter; the last shared reporter drop provides idempotent fallback cleanup. Later session selection, manual compaction and route-recovery decision prompts still need lifecycle reporting; configurable command hooks and sounds remain unimplemented. Socket failures are ignored and the 250 ms timeout applies only to receiving a response, as upstream specifies.
